Fantasy scoring note: Fantasy pts/game is calculated from this play-by-play file using standard half-PPR scoring rules (25 pass yds = 1pt, pass TD = 4, INT = −2, 10 rush/rec yds = 1pt, rush/rec TD = 6, reception = 0.5, fumble lost = −2; kicker and team-defense/IDP use common tiered scoring) — it is not pulled live from Yahoo or ESPN, since exact league settings vary. Also note: the source data has no position field, so Wide Receivers and Tight Ends are combined into one list.
